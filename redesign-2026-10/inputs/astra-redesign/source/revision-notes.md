## Discovery implementation handoff

The original SEO/GEO/AEO discussion in `../credtent-website-analysis.md` remains the source brief. These visual previews add useful visible headings, service distinctions, internal-link opportunities, and footer navigation. They do not implement discovery infrastructure.

- Build semantic HTML with readable page copy, unique descriptive titles, headings, crawlable internal links, image alt text, and consistent service/person/organization naming. Give valuation, training, citation licensing, and About distinct routes.
- Use structured data only for supported facts visible on that page. Validate it and avoid invented reviews, ratings, partners, or offers. Eligibility is not a guarantee of a rich result.
- Generate a machine-readable sitemap from canonical public routes, reference it appropriately, and test redirects, robots controls, indexing, and submitted URLs. A sitemap assists discovery; it does not guarantee indexing.
- Google’s AI features use established Search eligibility and SEO practices. No special AI schema or special AI text file is required. Maintain useful text, internal links, images, and up-to-date factual content. Treat broad GEO claims as hypotheses to measure with dated queries and analytics.
- Keep public marketing discovery separate from private uploads and training permissions. Decide crawler policies deliberately at implementation.
